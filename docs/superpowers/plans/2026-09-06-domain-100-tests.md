# 领域 100 测试用例实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 为组织、团队、工作节点、模板和对话五个核心领域各增加 20 个可执行 API 合同测试，共 100 个测试用例，并完成控制台测试、构建和静态检查验证。

**架构：** 测试直接调用现有 API wrapper，通过类型化的 HttpClient 测试替身断言路径、查询参数、请求方法、请求体和幂等键。五个领域分别使用独立测试文件，每个文件固定 20 个测试用例，避免跨领域共享状态；Worker runtime 筛选同时由控制器和仓储契约测试验证。

**技术栈：** Vitest、TypeScript、现有 `HttpClient` 抽象和 `normalizeCursorPage`。
